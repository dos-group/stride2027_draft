# STRIDE 2027

Website for the STRIDE workshop at EuroSys 2027. Plain static HTML/CSS/JS, no build step.

- Edit `index.html`, `style.css`, `script.js`.
- Preview locally: `python3 -m http.server` and open http://localhost:8000
- Deploy: GitHub → Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`.
